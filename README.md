# MoodFlix

A movie recommendation website that picks a film based on your mood — because choosing what to watch is harder than watching.
Built using live movie data from TMDB and designed to feel fast, fun, and cinematic.


## Features

* Pick a mood and get a movie recommendation  
* Dynamic posters fetched from TMDB  
* Randomized movie selection every click  
* Snack pairing suggestions  
* Personalized "why this movie?" descriptions  
* Re-roll for endless recommendations  
* Responsive and lightweight UI  

## Built With

- HTML
- CSS
- JavaScript
- TMDB API

## How It Works

User selects mood  
↓  
Mood → mapped to movie genres  
↓  
TMDB fetches matching movies  
↓  
One movie is randomly selected  
↓  
Poster + recommendation displayed
